# Page View Time Series Visualizer

This project visualizes daily page views for the freeCodeCamp.org forum from 2016-05-09 to 2019-12-03.

Use `time_series_visualizer.py` to draw:
- a line plot of cleaned daily page views,
- a bar chart of average monthly page views grouped by year,
- two box plots showing yearly trend and monthly seasonality.

Run `main.py` to generate `line_plot.png`, `bar_plot.png`, `box_plot.png`, and execute the unit tests in `test_module.py`.
